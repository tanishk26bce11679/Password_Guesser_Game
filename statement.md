# Project Statement

## Problem Statement

Many beginner programming exercises teach individual concepts separately. This project combines fundamental Python concepts into one interactive application: a Password Guesser Game. The player must identify a randomly generated password using feedback about correct characters and their positions.

## Scope of the Project

The project is a standalone, console-based Python game.

### Included

- Player name input
- Difficulty selection
- Random password generation
- Password guessing and feedback
- Hint functionality
- Attempt tracking
- Score calculation
- Session-based leaderboard
- Rules and menu system
- Basic input validation

### Not Included

- User accounts or authentication
- Permanent database storage
- Online multiplayer
- Web or mobile interface

## Target Users

- Students learning Python
- Beginners practicing programming logic
- Users interested in simple command-line games
- Instructors or evaluators demonstrating fundamental Python concepts

## High-Level Features

1. **Difficulty Levels** – Three levels with different password lengths, character sets, and attempt limits.
2. **Password Generation** – Creates a random password based on the selected difficulty.
3. **Guess Evaluation** – Shows exact matches and correct characters in the wrong position.
4. **Hint System** – Reveals a hidden character when requested.
5. **Scoring** – Calculates a score using attempts, difficulty, hints, and completion time.
6. **Leaderboard** – Stores and displays each player's highest score during the current session.
